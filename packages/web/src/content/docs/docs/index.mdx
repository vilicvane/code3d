Code3D connects TypeScript source with the geometry it produces. Write a model,
move through its expressions to inspect individual objects, and use visual
tools to make supported selections and parameter changes directly in source.

You will benefit from knowing JavaScript variables, functions, arrays, and
imports. Code3D uses ordinary TypeScript; you do not need to learn a separate
modeling language.

## Find what you need

- **Getting started:** follow a complete modeling task and learn the App.
- **Guides:** reuse model functions, add visual tools, work with an agent, and export models.
- **Concepts:** understand how source expressions and geometry stay connected.
- **Packages:** learn the modeling API, coordinates, topology, layouts, materials and fasteners,
  grouped by their full npm package names and labeled with their current versions.
- **[Comparisons](comparisons.md):** compare Code3D with code modeling libraries
  and CAD applications, one product and workflow at a time.

Try [making a hollow part](../../../../../core/docs/shells.mdx), [bending a loft with pivot
rotations](../../../../../core/docs/relations.mdx#bend-a-loft-with-explicit-rotations), or
[following a face's topology path](../../../../../core/docs/topology.md#ids-belong-to-a-model).
Each guide links to a complete editable example.

Learn how [local coordinates and placement](../../../../../core/docs/local-coordinates.md) fit
together, then [choose an origin and rotate a part](../../../../../core/docs/origins-and-rotation.mdx)
with a source preview for each step.
