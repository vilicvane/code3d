## Read the model

The stand needs no package installation, font download or agent connection.
Its side profile contains a foot, leaning back and retaining lip. Extrusion
sets its width; one box cuts the charging opening, and a small fillet softens
the edges. The result is one solid.

The main function comes first. The `sideProfile` helper at the end contains the
outline coordinates, so you can read the modeling steps before their details.

## Change the dimensions

Select the `phoneStand()` call to change width and angle using the parameter
tools. Inspect the function's Arguments presets to compare 70 mm / 20° with
85 mm / 25°. Edits update the source and geometry together; Undo restores both.
Select the charging-opening box to adjust its dimensions directly.

## Inspect the construction

Select `sideProfile(angle)` to inspect the input sketch, `extrude` to see the
width being added, or `cut` to inspect the opening and its input body.
`originOffset` centers the extrusion across its width; the rotation presents
the stand upright. The profile itself remains in its local sketch plane.

## Keep your own copy

The `/examples` directory is managed by Code3D. A new browser project's
`model.ts` imports the canonical stand function rather than copying the example.
Copy the stand source outside `/examples` and update that import before keeping
your own design changes across example updates.
