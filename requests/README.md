# Historical request archive

is the only live requirement tracker. A one-sentence issue is enough; no
template or prescribed sections are required. Do not add request files or move
them between directories to express status.

describe the pre-migration state, not current progress. Keep existing paths so
historical links remain valid. Old R-numbers are not unique; use the complete
source path when following a migration mapping.
