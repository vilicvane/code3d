# 研究记录

本目录保留仍有复查价值的实验来源、方法、数据和失败原因，按原实验时间解释。
这些材料不维护需求进度，也不替代[当前架构](../docs/README.md)。

| 记录                                                      | 保留理由                                                                                               |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [OndselSolver WASM](constraint-solver-wasm-evaluation.md) | 固定源码与工具链、Node/Worker 验证、冗余约束和局部非线性求解的边界；当前 Core/App 已不加载该独立求解包 |
| [二维草图求解器](sketch-solver-evaluation.md)             | PlaneGCS 选型证据、软目标分层、源码重放精度与共享圆弧稳定性调查                                        |

原生模块生命周期及 OpenCascade 资源释放实验还可从固定历史提交中的
[项目运行时验证记录](https://github.com/vilicvane/code3d/blob/933c3b5ec745e68dada4db42ecab8b6a0482ea2a/plans/core-package-and-node-projects.md#5-evaluation)
追溯。其内存、耗时和文件读取数属于当时环境，不能作当前性能承诺。

新的调查先在对应 issue 中确定范围。只有方法或证据值得长期复查时才形成研究
记录，并注明版本、环境、可复现入口与局限；实现采用的结论回到所属架构专题。
不为每次调试、验收或失败重跑新增一份研究文档。
