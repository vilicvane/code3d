# code3d visualization

修改视口可视化时沿用这些已确认的语义。用户的新判断覆盖旧实现；未明确的新视觉含义先讨论，不把临时方案写成约定。不要因为某条旧路径还使用不同尺寸或材质，就保留第二套样式。

## 屏幕尺寸与几何范围

- 辅助符号使用 CSS 像素，独立于模型大小、组合体/实体类型、实例缩放、相机缩放、视口尺寸和 DPR。不要再用模型包围盒对角线或固定模型单位决定符号大小。
- 面法向箭杆、轴两端的延伸箭杆、点与原点的圆点/十字、面与轴的中心圆环、参考坐标架均属于符号。3D 朝向仍有投影缩短；不要为了可见而篡改实际方向。
- 轴主体保留模型在该轴上的几何范围，包括组合体子对象；端部额外空间使用屏幕尺寸。真实曲线和面的范围来自其几何，不能随相机缩放改变。
- 可拖拽的平移箭头、旋转环也使用稳定的屏幕尺寸，但使用独立的操作控件尺寸，不必与被动辅助符号一样大。
- 在每次渲染使用当前相机与视口计算尺寸；图片导出使用导出相机和目标尺寸。不能只在创建时补偿缩放。
- 需要改变顶点缓冲的尺寸计算在 renderer 上传几何之前完成；不能放在对象的 `onBeforeRender` 中而滞后一帧。shader uniform 可在绘制回调中更新。

当前默认值集中在渲染器中；需要调节时修改共享定义，不在调用方加特例：

| 用途                     | 当前基准                    |
| ------------------------ | --------------------------- |
| 方向箭头头部             | 宽 6px、长 10px，实心三角   |
| 面方向箭杆、轴端延伸箭杆 | 28px                        |
| 圆环                     | 半径 4px                    |
| 点/原点圆点与十字        | 圆点半径 3px，十字半径 10px |
| pivot 中心点与圆环       | 圆点半径 3px，圆环半径 8px  |
| 参考坐标架               | 轴长 24px                   |
| 平移/旋转操作控件        | 基准长度 100px              |
| 拓扑顶点                 | 5px                         |
| 被动辅助线、源码高亮边   | 1px                         |
| 交互拓扑选择线           | 2px                         |
| 顶点/边拾取半径          | 6px                         |

## bound 与真实面

- bound 面是参考包围面，不能画成容易被误认成模型截面的完整矩形边框。
- 选中包围盒角线、bound 填充与方向标记共用黄绿色 `#d8ff3e`。bound 面不透明度 18%，角线 85%。用共享样式，不另设近似绿色。
- 同一个对象实例已有可见包围盒时，bound 只增加同色半透明填充；该实例没有包围盒时才补画面角线。按实际实例判断，不只看 node ID 或是否有 mesh；切换选择与重复实例各自更新。
- 包围盒与 bound 共用角线算法：从边的两端各取不超过 18% 的短段，投影长度上限为 32px。透视下两端分别计算；线宽固定 1px。
- 命名元素和关系 source/target 同时指向同一 bound 时去重，不叠加同一层填充。
- `.on` 左侧显示参与求解的完整包围盒，保留接触支撑面的填充和方向；右侧显示目标 bound 面。模型/组合体取整个几何范围，指定点、边、面时只取该元素的有限范围。包围盒直接来自当前阶段的求解快照，沿目标参考系计算，不能用整个所属模型或渲染网格的世界轴包围盒替代。
- 关系包围盒替代同实例的普通选择框；支撑面不再重复画角线，退出关系预览后恢复普通选择框。退化为平面或线的包围盒只画不重复的有效边。
- 真实模型面使用真实面组及其边界，保持青色面高亮语义，不套用 bound 参考面的角框。

## 方向与关系

- 方向头部共用 `ScreenSpaceArrowHead`，不要恢复随模型缩放的锥体箭头。
- 普通参考轴显示双向箭头；关系中的有向轴显示单个正向箭头，`reverse()` 和面的 `flip()` 尊重已有方向元数据。
- 曲线自身就是箭杆，只在有向端点放切向箭头头部，不另画短直线。反向曲线使用另一端及反向切线；闭合曲线使用稳定接缝点。
- 被动预览由通用 JSDoc inspector 返回的 `target` / `ambient` 决定，renderer 不根据建模函数名或工具状态拼装画面。层级依次为 target 中与 `context.focused.values` 同一对象的值、其余 target、ambient；生成的新几何不继承输入 focused。没有 focused 时全部 target 保持完整强调，不因选中 on/align 方法名而人为指定 self 为主侧。
- 工具可用性由当前源码调用及其参数元数据派生，不以 inspect 返回可预览值为前提。空参数或失败调用没有检查画面时，仍发布其源码工具上下文，让候选选择与参数补入可用；不为此伪造公共 inspector 返回值。
- 拓扑引用的空参数、无效 ID、空选择与有效选择共用所属模型的背景样式；有无已选元素只影响元素标记。缺失结果所需的被动背景由接口 inspector 声明，不在工具补画时退回普通模型材质或按方法名猜测预览层级。
- 标记在 target:focused / target 层级分别保留基础不透明度或整组乘 0.7；没有 focused 时 target 使用基础不透明度。箭头、圆环、角线、范围框、真实边界及面填充一起变化，例如 bound 角线 85% / 59.5%、填充 18% / 12.6%。同一锚点的别名只画一次，最强层级生效；同属一个模型的不同元素仍保留各自身份。
- relate 调用的 target 是返回对象，ambient 只包含本次实际消费的其他参与者，不按下游组合扩张背景。closure 中先尝试内部参数/调用 inspector，再由 closure inspector 判断归属；无关值放行，集合必须全部成员相关才接管。普通表达式值和工具的当前操作对象分别判断，不能把工具使用 self 当成被动 focused 的来源。
- 普通表达式值预览保留模型材质本身的 opacity，不套用 inspect 层级上限；未指定材质的模型面仍使用默认 0.68。适用于单值、集合、组合体、普通调用结果、参数回退结果与补全预览。内部场景显式区分 preview / inspect 并随 Worker 传输、暂存恢复及截图使用，不靠 target 数量或 ambient 是否为空猜测。原始 Anchor 的所属模型仍是上下文背景。
- inspector 场景中的模型透明度用于保证能看穿，采用 `max(材质透明度, 检查透明度)`，即 `opacity = min(材质 opacity, 层级上限)`，不与材质 opacity 相乘。focused 或无 focused 的 target 模型面上限 0.82，其余 target 模型面上限 0.4、线与点上限 0.5；主次必须在默认材质下也可辨认，不能依赖额外关系标记或只用不透明自定义材质验证。两侧保留模型颜色，外围使用淡灰上下文，面上限 0.18、线与点上限 0.28；不能把本来更透明的材质变实。点、曲线、实体和组合体子对象都遵循此规则，切换选择后重新判定。模型阈值与标记倍率各自定义。
- cut 工具与 intersect 输入的参数 inspector 明确把选中的输入放入 target、其他输入放入 ambient；切入体积和交集也是 target，但不继承输入 focused。结果的语义颜色及前景显示由 inspector 的普通 material 值表达，不恢复按操作名分类的渲染分支。非 ambient 的 `depthTest: false` 材质须在普通半透明模型之后合成，不能只关闭深度测试却仍被透明绘制顺序遮住；辅助区域使用不受灯光与 tone mapping 改变的颜色。数组成员、整体数组和往返切换都验证实际画面及导出，不能只检查 focused 字段或材质配置。
- source 与 target 的头部尺寸、形状一致；不以空心、放大或颜色变化表示主次。关系标记仅从当前选中的 align/on 关系生成；同段其他约束仍共同求解但不叠加轴面高亮。独立 self 表达式和 offset、pivot/pivotPoint/pivotVertex/axisEdge/axisLine/rotate 不显示无关关系标记，当前工具原点或旋转参考由工具保留。on/align 接收者或参数的显式 inspect 可显示该约束标记；不再叠加命名元素和旧拓扑预览 provider。
- 标记关注侧与引用值的归属分别保留；例如在 `axisLine(axis.axis)` 内强调 self 时，成员补全仍作用于 axis。未编译的成员候选预览不能混用旧关系快照；编译完成后恢复完整关系预览。
- 面箭头沿面法向；方向元数据与 offset/旋转参考坐标架保持各自含义。
- 整个 relate(...) 范围都显示空间工具入口，包括 self.axis、目标侧引用和回调块体；嵌套 relate 归最内层 self，循环保留当前执行实例。入口可用性与具体表达式的参数面板、轴面高亮和 gizmo 绑定分别派生；点击工具后才导航到 self 的变换，不能因正在查看目标引用就修改目标零件，也不默认激活工具。
- relate 中显式调用显示的姿态、参考几何和工具必须来自同一个当前阶段快照；不能混入光标之后的 offset/rotate 结果。仅选择裸 self 时显示所属摆放段的完整结果；点击工具后，已有对应操作立即激活其完整表达式末尾和阶段，没有对应操作则显示实际插入位置之前的阶段。坐标架、候选和标记随该阶段同步，不能等首次拖动才切换。
- 数组空白保留该位置的插入能力，激活工具时同样先比较紧随其后的 transformation，匹配才进入该项；否则光标留在插入空白，不借前一调用的名称高亮。预览只使用当前 relate 回调开始前的继承关系及空白前的条目；完成后的回调不能让后续条目混入前缀。数组项起点 |self.axis.align(...) 视为 self；当前调用匹配则继续编辑，否则只比较后面最近的一项 transformation，匹配就激活，不匹配就在它之前新增；不能越过其他变换或后续约束段。源码目标统一决定标记、面板、手柄与参考候选，binding 不另行查找调用。
- 关系阶段预览保留同一连续约束段的兄弟约束，联合求解；变换按当前操作截断为选中阶段，不能把各条关系拆成独立位置。独立 Transformation 截止当前操作，同一源码的循环实例各自使用对应阶段快照，不能只更新焦点实例而让其他实例混入后续操作。后续约束属于新段；选择 self 时展示所属段的完整变换结果。当前关系的高亮范围不改变该段求解范围。

## 颜色、层级与交互

- 背景网格普通线使用背景色的 RGB 反色，主次格线通过不透明度区分强弱，不另指定灰色；穿过原点的中心线使用对应的 XYZ 轴色，颜色按线延伸的实际轴向归属。
- `expose` sources 参数通过 inspector 显示已有组合中的命名引用，receiver 为 ambient；调用 identifier 默认预览返回对象。上下文只来自 inspector 的明确结果，不按调用输入或下游组合隐式扩张。
- 选择对象本身不改其材质；源码上下文的明暗对比表达焦点，组合体可用被动包围盒标记。参数预览对其他受影响对象使用独立的次级颜色。
- 拓扑可选项为暗灰，预览/选中为黄绿色，悬停未选中为青色，悬停已选中为橙色。悬停只改颜色，不改变尺寸，也不叠加面的填充透明度。
- 参考轴及绕轴旋转弧线使用橙色 #ffad4d，无论是否与 XYZ 重合；真实面使用青色，绕点旋转与参考平移的 XYZ 控件沿用现有轴色。颜色服务于既有语义，不为新增入口自创近似色。
- 辅助标记的基础颜色不受灯光或 tone mapping 改变；透明度和层级单独处理。点/箭头应可辨认，不能被模型的透明绘制顺序遮住。
- 模型面和自动生成的边界共用深度测试策略；背景、普通模型和前景各层都先画面、再画边。边界不写深度，前景边界也不参与深度测试；不能只抬高面而把边留在普通层，也不能把面边设为相同顺序后依赖相机距离排序。普通模型与 inspect 使用同一层级定义，嵌套组合、旋转后的屏幕绘制与图片导出一起验证，并检查实际边界像素。
- 平移工具显示当前阶段的零件原点，随几何的平移预览移动；旋转工具显示对应 pivot/axis。标记由当前工具派生，不能只按源码邻近的旋转选择参考。尚未写入旋转的插入位置也从激活绕点工具起显示默认 pivot，不能借用前面旋转的中心；Alt 只切换参考平移手柄，不改变标记。绕轴插入在选轴前不画虚构的参考点或轴。
- origin 使用黄绿色 `#d8ff3e` 十字加中心点；pivot 使用橙色 `#ffad4d` 圆环加中心点。pivot 作为点没有优先平面，圆环始终朝向屏幕；参考轴和面仍使用真实空间方向。静态、拖动和提交等待期间共用一个标记来源，每个实例根据当前预览投影，不恢复旧点或叠加独立预览层。
- 原点与 pivot 标记绘制在 gizmo 上方，静态与拖动预览使用相同前景层级。嵌套标记组也须保留该层级；Three 的子 Group 会重置渲染分组顺序，不能只设置外层 Group。
- 装饰不参与对象选择或导出的 CAD 几何。顶点/边按屏幕距离拾取，面按几何相交拾取；相机或预览变化后更新悬停结果。

- 空间工具拖动始终遵循网格或角度吸附。Shift 临时使用图例大格（5 个小格）位移或相对拖动起点的 15° 实际转角，和 Alt 可组合；位移的小格在手势开始时冻结，中途切换 Shift 从原始 delta 重新量化，不累加误差、不改变文本框步长。relate 工具栏区分平移、绕点旋转和绕轴旋转，两种旋转在变体菜单中选择；各旋转工具的 Alt 临时切换到对应参考的平移，手势开始后固定操作。relate 平移工具不响应 Alt；模型 originOffset 工具在 Alt 待机时将 gizmo 移到对象当前世界包围盒中心，保持原轴向，松开恢复原点；Alt 手势拖动对象、固定原点标记，仍写入 originOffset。旋转工具自动显示对应点/轴候选，点选不依赖 Alt；Alt 只切换对象旋转与参考平移 gizmo，松开后仍保留候选。手柄拾取优先。选择器和 rotate 共用工具及参数面板。 绕点与绕轴属于不同工具：激活时按相邻项规则决定复用或插入，参考编辑写入已选同类调用，插入时创建新操作并保留已有旋转；单纯切换工具不改源码。未填完的 pivotVertex、pivotPoint、pivot、axisEdge、axisLine 及其偏移链仍保留当前 relate self 与已完成前置阶段的参考选择，不能借用上一条旋转绑定。选参考时同一事务补齐缺少的 rotate（点为三个零角度，轴为一个），已有旋转角度和偏移保留，重新求值后进入完整旋转 gizmo；未交互不改源码。未完成选择器也立即展示参考、已有偏移和旋转角度的完整面板，缺少 rotate 时显示零角度，实际编辑角度才补写调用。源码提交后，能准确预览且源码锚点有效的既有操作更新参数与坐标基准，保留连续编辑；新增调用、缺少有效写入目标或准确预览时等待新模型。不能只以编译中为理由隐藏，也不能混用同一 occurrence 上不同操作的快照。

## 测距

- `distance` 预览保留调用时的参与元素和共同求解位姿，调用名与空白处同等强调两个被测对象，关系上下文作为灰色弱化背景。整实体及 group 输入保留已有模型外观，不套用真实面的青色填充；空心或复杂实体的多个表面叠色会掩盖主次差异。内部参数保留普通源码焦点：变量突出实体、另一实体灰色弱化；元素引用突出该元素，所属模型弱化，另一被测侧标记使用与关系相同的次级不透明度倍率；同属一个实体的不同元素仍分别判定。沿用真实面、有限边、点和 bound 的现有样式；测量 bound 默认只保留参考面与角线，明确选中某个 bound 时仅恢复该 bound 的法向标记。
- 普通距离线连接真实最近点；沿轴距离线表示投影区间间隔；横向位置优先取两侧 bounds 的投影重叠范围中点，使点落在目标面的投影内时辅助线从点出发。横向范围不重叠时取最近边界的中点。一般几何的参考端点不保证是拓扑点。重叠显示 0；距离标注使用灰阶虚线、两端短刻线和中性数字。虚线节距、刻线和数字保持屏幕尺寸；X/Y/Z 字母复用视口对应轴色，自定义方向的 axis 文字保持中性色。标签不参与拾取或 CAD 导出。
- 不以测量结果相等关联源码，不因后续使用该数值而扩张测量上下文。操作范围对照以[相关实体表](../../docs/architecture/tooling.md#相关实体与源码预览范围)为准。
