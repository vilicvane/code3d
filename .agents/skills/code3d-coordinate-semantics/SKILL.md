# code3d coordinate semantics

## 坐标归属

模型有自身局部坐标，整体没有脱离组合上下文的外部绝对位姿。局部几何与模型在组合中的实例位置分别表达；`relate()` 的摆放在组合中解释，单独检查模型时使用自身局部几何。

布尔结果使用主操作数的局部坐标，loft 使用第一截面的局部坐标；group 保留组合形成的局部摆放。

处理坐标时先明确它属于哪个模型值、实例或参考元素。模型局部轴、线/面锚点的参考坐标架、组合位姿和视口世界坐标各有归属；同样的 XYZ 数字不代表同一个方向或位置。`expose()` 将引用带入外层模型的局部空间，重复实例通过具体 occurrence 解析。

关系中的约束共同求解位姿，未约束自由度采用求解器的默认结果。约束链的 `offset` 在原有解的前提下，沿目标参考架平移 self；不得额外固定切向位置或隐式居中。`offset(0, 0, 0)` 不改变解。旋转同样作用于该链原有解，零角度不新增朝向约束；pivot 属于 self 局部坐标，外部 axis 使用其已求解的组合位姿。`offset` 与 `rotate` 严格按调用顺序执行，不跨旋转合并位移。目标架属于当前操作阶段；局部动作与外部轴动作各按所属参考系组合。其他关系仍约束最终结果；约束之外的独立后置 transformation 另有职责。

## 原点

原点定义模型坐标，在自身坐标系中恒为零。`originOffset(d)` 保持轴向，使内部点的坐标变为：

```text
p_new = p_old - d
```

几何形状、点间相对关系和拓扑身份不变，点坐标改变。顶点、控制点、`center`、具名锚点及参考坐标架的位置遵守同一变换；方向、切向和法向不减去偏移。`center` 仍是原来的几何点，其坐标随变换更新。

所有模型提供 `originOffset()` 和 `originPoint(pointRef)`；后者把所选点转换到 receiver 的局部坐标，再让它成为零点。几何模型的 `originVertex(id)` 等价于选择自身拓扑顶点，`originCenter()` 选择已有 `center` 点。group 不引入聚合顶点 ID 或几何 center。

group 构造时先求解直接成员位姿，随后继承第一个成员的完整局部坐标系（原点及轴向），与 union/intersect 的首个操作数、cut 的被切零件、loft 的第一截面一致。成员间相对装配不变；顺序可以改变结果坐标系。嵌套 group 作为一个完整成员，不展开其子成员重新定原点；空 group 使用默认零点和轴向。成员原点重合时，group 原点就是该重合点，支持 originOffset + group 直接装配。

group 默认原点仅在构造时确定；后续原点操作统一重表达已装配结果，保持成员间相对位置和内部约束，不逐个改子模型原点再重求解。显式原点不被后续 copy/material/expose/relate 重算覆盖。成员点按实际 occurrence 转到 group 局部坐标；重复来源有歧义时要求具体实例引用。模型已有关系中的自身参考元素同步重表达，继续约束同一几何点。

`.origin(x, y, z)` 没有独立语义：原点没有可赋予的模型内坐标，表达相对偏移则已有 `originOffset()`。

原点偏移可以累加和抵消，操作产生新模型值，旧值及其引用保持不变。所有模型的 `rotate(x, y, z)` 围绕当前局部零点，按固定局部 X、Y、Z 顺序旋转；几何模型的缩放同样围绕当前局部零点；显式 pivot 或引用轴另行指定旋转中心与方向。曲线参数起点、几何中心和模型原点各有自己的含义。

group 直接旋转统一变换保存的装配位姿，保持嵌套实例及内部关系，不逐个旋转子模型或重求解。具名引用与拓扑随成员变换；方向 bound 仍按接收模型的固定局部轴查询。原点保持零，后续原点操作使用已旋转结果的坐标。

## 参数与坐标构造器

坐标位置使用数组，例如 `pivot([x, y, z])`。`originOffset(dx, dy, dz)`、关系 `offset(dx, dy, dz)` 表达位移增量，`rotate(x, y, z)` 表达各轴角度，使用独立数值参数。

图元构造器用独立数值表达尺寸，用数组表达局部坐标。`box(10, 20, 30)` 按尺寸构造，几何中心位于局部原点；`point([x, y, z])` 创建指定坐标的点，`point()` 创建局部零点。不使用 `point(x, y, z)` 或 `line(x, y, z)` 的标量坐标形式。

便捷构造器有清楚的语义等价，就可以保留：

```text
point([x, y, z]) ≡ point().originOffset(-x, -y, -z)
```

`line([x, y, z])` 从局部零点连接到指定端点；`line(start, end)` 的两个参数均为坐标数组。曲线控制点同样使用返回模型的局部坐标。输入中的共同平移量描述几何相对于原点的位置，不能擅自归零。等价关系应在后续变换与组合中仍然成立。

模型原点与几何中心分别理解：`line([10, 0, 0])` 的原点为 `[0, 0, 0]`，几何中点为 `[5, 0, 0]`。绕模型 Y 轴旋转 90° 后，其端点为 `[0, 0, -10]`；线的切向参考架不替代模型 XYZ。

`originOffset()` 改变内部坐标，关系链的 `offset()` 表达组合摆放；分别使用各自所属的参考系。

## 存储与交互

内核表示可以采用惰性变换。轴向一致时，若存储点为 `P`、模型原点在存储系中的位置为 `O`，语义坐标就是 `P - O`；只更新 `O` 也可以实现原点偏移。同时缩放二者满足 `sP - sO = s(P - O)`。以几何运算、查询、渲染和导出的可观察行为判断等价，不要求逐次重写底层顶点。

稳定状态以结果模型的局部原点为参考。拖动原点时固定使用手势开始的 snapshot，在它的坐标系中显示候选位置 `d`，每帧都由开始状态与总位移计算，不把上一帧预览作为新基准。提交后回到结果模型坐标，原点为零、几何为 `p - d`；取消恢复开始状态。源码写回与重新求值表达同一变换，不把拖动参考系中的标记坐标当成输出模型的原点坐标。

拓扑候选的身份和几何归属分别处理：修改操作参数时，候选 ID 可以来自输入模型；候选的绘制、悬停和拾取必须使用输入几何到当前显示结果的坐标变换，再应用实例位姿。`originVertex()` 重设原点后，候选顶点仍贴合长方体；输入的旧坐标不能直接当作结果坐标。

派生辅助几何也要明确所属模型，再使用当前可见实例的位姿。布尔重叠区域属于主输入的坐标；形状变化可能影响结果模型的关系求解位置，不能借用结果位姿来放置输入辅助几何。原点等操作参考标记与随几何移动的锚点分别处理，提交到重新求值之间的临时状态也须遵守，不能重复应用几何偏移。
